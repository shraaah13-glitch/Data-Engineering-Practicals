# Practical 1 – Data Parsing, File Handling and Database Operations

## Aim

To perform data parsing, file handling, regular expressions, and CRUD operations using Python.

## Software Used

- Python IDLE
- Python 3
- SQLite

## Technologies Used

- CSV
- JSON
- XML
- HTML Parser
- Regular Expressions
- Struct Module
- SQLite

## Objective

- Parse TXT, CSV, HTML, XML, and JSON files.
- Identify missing values and data anomalies.
- Read and write binary files.
- Perform Regular Expression operations.
- Perform CRUD operations using SQLite.

## Description

This practical was performed using **Python IDLE** and demonstrates different methods of handling and processing data using Python.

### Part 1 – File Parsing

TXT, CSV, HTML, XML, and JSON files are parsed, and missing values and anomalies are identified.

### Part 2 – Binary File Handling

A binary file is created using the `struct` module, and integer values are written and read from the file.

### Part 3 – Regular Expressions

Regular expressions are used to find email addresses, find a phone number, split text, and mask email addresses.

### Part 4 – SQLite Database

An SQLite database is created and CRUD operations are performed:

- Create
- Read
- Update
- Delete

## Output Files

- `numbers.bin`
- `students.db`
- `console_report.txt`

## Result

Thus, the Python program successfully performed data parsing, file handling, regular expression operations, and SQLite CRUD operations using Python IDLE.
