# Practical 4 – Noise Elimination, Feature Selection and EDA

## Aim

To perform noise elimination, feature selection, and exploratory data analysis using Python.

## Software Used

- Python IDLE
- Python 3

## Technologies Used

- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- VarianceThreshold

## Objective

- Create a sample dataset using Pandas.
- Identify and remove noisy data using the IQR method.
- Perform feature selection using VarianceThreshold.
- Analyze the dataset using statistical methods.
- Generate correlation matrix, histogram, and boxplot.

## Description

This practical demonstrates data preprocessing and exploratory data analysis techniques using Python.

### Part 1 – Noise Elimination

The IQR (Interquartile Range) method is used to identify and remove noisy or outlier values from the `Age` column.

### Part 2 – Feature Selection

The `VarianceThreshold` method is used to remove features with zero variance.
The constant feature is removed because its value remains the same for all records.

### Part 3 – Exploratory Data Analysis

The cleaned dataset is analyzed using:
- Dataset information
- Statistical summary
- Correlation matrix

### Part 4 – Data Visualization

The following visualizations are generated:
- Histogram of features
- Boxplot of the dataset

## Result

Thus, noise elimination, feature selection, and exploratory data analysis were successfully performed using Python, Pandas, Matplotlib, and Scikit-learn.
